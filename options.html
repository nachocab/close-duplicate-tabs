Matching rules

Tabs are duplicates when their URLs match, ignoring the #fragment and the order of query parameters. Rules change that for URLs you name: they loosen the comparison, so pages whose URLs carry throwaway values — a random localhost port, a one-time OAuth code — still group together, or they mark a URL as closable on sight.

Rule fields keep the order you write them in. Saving stores this text as typed.

Rule fields

Field Meaning
match Required. Which URLs the rule applies to. * stands for any run of characters and is the only special character; everything else is literal. The whole URL must match.
ignorePort Group tabs that differ only by port number.
ignoreParams A list of query parameter names to drop before comparing, or "*" to drop the query string entirely.
matchTitle Also require equal tab titles. This narrows a rule and never widens it: two tabs still need the same origin and path to group. Use it when a rule drops so much of the URL that the title is the only thing left telling two pages apart.
closeAlways Close every matching tab, duplicate or not. For pages that carry no information once you have read them, such as a you may close this window callback. This is the one field that can close the tab you are looking at, and it ignores pinning, so keep its match narrow. It compares nothing, so it cannot be combined with the three fields above.

The first rule whose match fits a URL is the one that applies.

Examples

A local OAuth callback listener binds a random port per run and the code is single-use, so neither belongs in the comparison. The title is what identifies the page: 

[
  {
    "match": "http://127.0.0.1:*/oauth/callback*",
    "ignorePort": true,
    "ignoreParams": "*",
    "matchTitle": true
  }
]

Or, if such a page is only ever there to be dismissed, close it on sight instead of keeping one of them: 

[
  {
    "match": "http://127.0.0.1:*/oauth/callback*",
    "closeAlways": true
  }
]

Dropping one noisy parameter, such as a banner message:

[
  {
    "match": "https://*.console.aws.amazon.com/*",
    "ignoreParams": ["warningMsg"]
  }
]
